# DLS Method

## Definition

The Duckworth-Lewis-Stern (DLS) method is the mathematical formula used to calculate target scores for the team batting second in rain-reduced limited-overs cricket matches.

## Purpose

This rule was introduced to replace the flawed most-productive-overs method and average run rate method, providing a fair target by accounting for both resources remaining: overs and wickets in hand.

## Key Rules

* It is triggered when match time is lost due to weather, bad light, or other unavoidable delays.
* The system evaluates two resources: the number of overs remaining and the number of wickets lost.
* Wickets are treated as valuable resources; losing wickets lowers the projected total, making the revised target harder to achieve.
* A minimum number of overs per innings (usually 5 overs in the IPL) must be bowled to constitute a match using DLS.
* If play is interrupted multiple times, the target is recalculated dynamically after each stoppage.

## Example

In an IPL match, Team A scores 180 runs in 20 overs. Rain interrupts the second innings, reducing Team B's allocation to 10 overs. Using the DLS method, the software assesses that losing 10 overs costs Team A roughly 50 percent of their resource pool, generating a revised target of 95 runs from 10 overs for Team B.

## Recent Changes

The DLS system undergoes continuous software updates by the ICC. Modern applications utilize advanced algorithms based on recent T20 scoring trends and data from thousands of international and domestic matches to calculate resource percentages more accurately.
